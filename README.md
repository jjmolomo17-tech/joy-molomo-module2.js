## Project Description

This project was completed as part of the JavaScript Essentials Module 2 checkpoint assessment. The goal of the project was to strengthen my understanding of JavaScript fundamentals, including variables, data types, type conversion, type coercion, arithmetic operations, debugging, and code review skills. Through the different challenges, I learnt how JavaScript handles values behind the scenes and how important it is to use explicit type conversions to avoid unexpected results. I also gained confidence in reading, explaining, and debugging JavaScript code, which are essential skills for technical interviews and real-world software development.
